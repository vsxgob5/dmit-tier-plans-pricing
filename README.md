# DMIT 评测：Pro / Eyeball / Tier 1 三档线路怎么选，洛杉矶、香港、东京全套餐价格与换 IP、退款规则一次说清

搜「DMIT 评测」的人，通常已经绕了一圈了。搬瓦工看过了，几家$3一个月的也看过了，然后在论坛里反复看到同一个名字——大妈。于是就冒出一堆具体问题：CN2 GIA 到底比普通线路好多少？同样 2 核 2G，为什么 Pro 和 T1 能差好几倍价钱？香港那么贵真的值吗？

这篇不打算从头讲公司故事，直接按你下单前真正需要判断的顺序来：线路分档、硬件平台、实测数据、价格表、优惠码、以及三条特别容易被忽略的规则。

## DMIT 是谁，为什么总在讨论区出现

美国纽约注册的商家，第三方资料里注册年份有 2017 和 2018 两种说法，其中一个来源提到公司编号 5246271。主营 KVM 虚拟化 VPS，机房在洛杉矶（LAX）、香港（HKG）、东京（TYO）三地。

它的定位一直比较清楚：不做最便宜那一档。硬件全系 AMD EPYC 处理器配企业级 NVMe SSD，线路走 CN2 GIA、CMIN2、AS9929 这类回国优化路线，对外宣传的核心是**不超售**。付款支持支付宝、微信、PayPal 和信用卡，有中文客服——对国内用户来说，这两点比参数表更能决定要不要继续往下看。

洛杉矶是它自己的 AS906 和自持 IP 段，第三方 IP 质量检测里显示为原生 IP，风险评分偏低，某次实测能解锁 TikTok、Netflix 之类的流媒体。注意，商家本身不做解锁保证，这一项只能算加分项，不能当卖点写进决策。

## 评测之前先分清三档线路

DMIT 的套餐命名第一层不是配置，是网络类型。同一个「1 核 2G 20G」的壳子，挂在 Pro 下面和挂在 T1 下面，价格能差出几倍。

| 网络类型 | 简称 | 路由特征 | 适合谁 |
| --- | --- | --- | --- |
| Premium | Pro | 含电信 CN2 GIA，三网回程优化，亚太及大陆方向优先 | 对大陆访问体验有硬要求，不接受晚高峰波动 |
| Eyeball | EB | CMIN2 / CMI 等中国方向优化，回程走 AS9929 或 CMIN2 | 预算优先，但希望大陆住宅用户访问明显好于普通国际线路 |
| Tier 1 | T1 | 纯国际 BGP，无中国大陆专项优化，接入 RETN / Telia / Cogent 等 | 海外建站、中转落地、备份、CI/CD，或只需要一个当地 IP |

一句话判断逻辑：**主要用户在大陆，选 Pro；预算卡得紧又要大陆体验，选 EB；只做国际业务，T1 就够。**

有个坑值得单独提一句：香港 T1 对电信用户来说，延迟有可能比美国还高。原因很简单，T1 的定位是国际互联，路由不走大陆方向，电信流量绕出去再绕回来很常见。买之前先用官方 Looking Glass（lg.dmit.sh）跑一下自己的线路，比看任何参数表都实在。

## 硬件平台是第二个变量

DMIT 的机房同时在跑多代硬件平台，命名里的 AS3 / AN4 / AN5 指的就是这个。第三方资料里比较一致的划分是：AS3 用 AMD EPYC 7003 系列，AN4 用 EPYC 9004，AN5 再往上一代。

这件事对评测的意义在于——**同一款套餐名，在不同平台上的价格是不一样的**。比如洛杉矶 Premium TINY（1 核 2G 20G 1T），第三方整理出来的月付价格出现过 $9.99（AN4）、$10.90（AS3）、$12.98（AN5）三种。都不是假数据，只是平台世代不同。

> 所以看到「DMIT Pro.TINY 多少钱」这种问题，先别急着对答案。得看那台机挂在哪代平台上、是不是当月有货。下单页上显示的价格才是唯一有效价格。

库存也是常态变量。第三方补货记录里，AN4 平台曾因硬件资源耗尽关闭销售，洛杉矶 Pro.MINI、Pro.MICRO 一类热门机型以及香港、日本部分配置反复出现售罄。想买热门款，光比价没用，得盯着补货。

## 第三方实测数据能看出什么

下面这些数字来自不同的第三方测评，测试时间、节点和脚本都不一样，只能当参考量级看，不能当成你一定会拿到的结果。

- **香港 Pro**：某次平台实测三网平均 Ping 约 43ms，电信和联通各约 42ms，移动约 46ms，几乎无丢包。这是三地里最低的。
- **洛杉矶 EB**：同类测评里三网平均约 159–163ms，电信、联通、移动差不多打平。回程移动走 CMIN2、电信和联通走 AS9929。
- **洛杉矶 T1**：同一批测评里三网平均约 208ms，港澳台节点约 154ms。T1 本来就是国际线路，这个数字符合预期。
- **东京 EB**：某次测评三网平均约 131ms，但分运营商看差异很大——电信约 84ms、联通约 80ms、移动约 232ms。移动那项明显偏高，如果你的用户主要在移动网络，这个数据值得多测几次再决定。

硬件侧的记录：AN5 平台的 EB TINY 实测 Geekbench 6 单核跑到 2650 以上；另一批 AN4 EB 的测评里硬盘 I/O 约 1.1GB/s。都是单次测量，别当跑分承诺，但至少能说明这台机器不是靠降配换价格的。

想自己验，第三方整理的测试 IP 大致是：洛杉矶 Pro `154.17.30.96`、洛杉矶 EB `154.17.226.2`、香港 Pro `103.117.100.199`、东京 Pro `45.88.193.23`。

## 换 IP、退款、超量：三条容易被忽略的规则

这三条比价格更容易影响你的实际体验，而且大多数人下单前根本没读。

**换 IP。** DMIT 的政策写得挺细，Pro 和 Eyeball 系列可以免费换 IP，但要同时满足四个条件：实例已开通满 7 天、距上次换 IP（含付费更换）至少过了 15 天、ICMP 和所有 TCP 端口都被封、服务剩余有效期至少 7 天。四个条件缺一个都不行。付费换 IP 是每次 $5，门槛低一些：实例满 24 小时、距上次更换满 24 小时、剩余有效期超 24 小时。Tier 1 系列不提供免费换 IP，只能付费，且要求距上次更换满 3 天。另外，IP 是系统随机分配的，不能指定段，换完也不退。

对比一下，搬瓦工同类产品的换 IP 费用是 $8.79 一次。DMIT 那个「每 15 天免费一次」，是它相对同类里比较实在的一项。

**退款。** 第三方多份资料的说法一致：购买 3 天内且流量使用不超过 30GB 可以全额退，30 天内按剩余价值退，会扣掉支付网关的手续费。这个窗口不长，所以**先买月付测一周再决定要不要转年付**，是比直接上年付更理性的做法——尤其考虑到年付能打折，很容易被折扣推着跳过测试环节。

**超量。** 这条值得单独拎出来，因为它是 DMIT 和不少同行最大的体验差别之一。Pro 和 EB 系列流量跑完之后不停机，直接降到 4Mbps 到 10Mbps（按套餐档次）继续跑，不额外计费。T1 系列的降速档位高得多，WEE 是 50Mbps，TINY 到 MINI 是 100Mbps，往上是 200Mbps 到 1Gbps。

> 换句话说，T1 系列在流量维度上更接近「大带宽不限流量」的用法。如果你有稳定的高流量需求但不需要大陆优化，T1 的超量降速档比 Pro 的 4Mbps 实用太多。反过来，4Mbps 大概只够日常网页和轻量 SSH。

## 什么情况适合 DMIT，什么情况不适合

判断标准其实不复杂。

**适合**：用户或业务对象主要在中国大陆，对晚高峰稳定性有要求，并且能接受每月 $10 起的起步价；或者做海外建站、中转落地、跨境业务，需要 T1 这种低门槛大带宽的节点；又或者你所在的运营商正好和某条线路匹配——电信配洛杉矶 Pro 或香港 Pro 的 CN2 GIA，移动配 EB 系列的 CMIN2 或 CMI，踩对了差距很明显。

**不太适合**：纯价格敏感型，只想要个位数美元一个月的机器——DMIT 的入门价在同类里不算低，T1.WEE 年付 $36.90 已经是地板了；主要服务用户完全在海外、不涉及大陆访问——这种情况下为 Pro 的 CN2 GIA 付溢价属于买错方向，直接 T1；还有预算很紧又要低延迟的，说实话这个组合在 DMIT 里不存在，只能往上加预算或者降低心理预期。

一个经常被忽略的现实：热门款长期缺货。你要的那台有没有货，比它多少钱更重要。

## 常见问题

**DMIT 和搬瓦工怎么选？**

同线路条件下 DMIT 价格通常更低，第三方对比里提到同等线路下大约是搬瓦工的一半左右，香港 Pro 的入门价 $39.90 对搬瓦工香港 CMI 的 $89.90 起。防守方向反过来：搬瓦工的退款窗口更宽松（30 天内流量不超 10% 可全额退），DMIT 只有 3 天。换 IP 是 DMIT 便宜，$5 对 $8.79。硬件世代也是 DMIT 更新一些。

可以，而且建议这样做。但要注意两点：月付用不了大部分年付折扣码，很多热门套餐默认只开放季付或年付。有第三方记录提到，AN4 关闭销售后新平台开放了月付和季付选项，具体可选项以下单页为准。

支付宝、微信支付、PayPal，以及 Visa / MasterCard 这类信用卡。有中文客服。
